Connection experiment

Can Chrome reach GitHub Copilot through the official SDK?

This private, unofficial prototype has no network access of its own. It talks only to a companion on this Mac, which runs the official GitHub Copilot SDK. Page capture is outside its scope.

Connect with a PAT

Use a fresh, expiring fine-grained PAT with your personal account as resource owner and Copilot Requests permission only.

The panel hands the token to the local companion and clears this field. The companion keeps it in memory until you clear or close this panel. Never paste it into chat or an issue.

Try one response

Only models the SDK reports as enabled for your account are offered. The session has no tools, so it cannot read files or run commands.
