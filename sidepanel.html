Connection experiment

Can Chrome reach GitHub Copilot directly?

This private, unofficial prototype explores extension-only access. PAT compatibility is not yet verified; page capture is outside its scope.

Start without a token

Check the interface and streaming with synthetic data entirely offline. A successful demo does not establish Copilot access.

Check a PAT

Use a fresh, expiring fine-grained PAT with your personal account as resource owner and Copilot Requests permission only.

The token stays in this panel's memory. Closing or reloading the panel clears it. Never paste it into chat or an issue.

Try one response

Only models explicitly marked enabled and compatible with Chat Completions are offered. A discovery failure stops the experiment; it does not trigger another authentication method.
