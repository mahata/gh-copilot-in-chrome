Copilot in Chrome (unofficial)

Chat with GitHub Copilot from Chrome through the official SDK.

This private, unofficial prototype has no network access of its own. It talks only to a companion on this Mac, which runs the official GitHub Copilot SDK. Page capture is outside its scope.

Connect with a PAT

Use a fresh, expiring fine-grained PAT with your personal account as resource owner and Copilot Requests permission only.

The panel hands the token to the local companion and clears this field. The companion keeps it in memory until you disconnect or close this panel. With Remember checked, it also saves the token in your macOS login keychain once GitHub accepts it. Never paste it into chat or an issue.

Connecting starts the Copilot SDK on this Mac, which checks the PAT with GitHub and lists your models. No prompt is sent.

A PAT is saved in your macOS login keychain. While it is saved, the panel connects with it each time it opens.

Chat

Every prompt you send is a live request that uses your Copilot allowance at the chosen model's billing multiplier. Stopping may not prevent server-side work or charges.

Only models the SDK reports as enabled for your account are offered. The session has no tools, so it cannot read files or run commands, and replies appear as plain text.

⌘ Enter or Ctrl Enter sends. Enter starts a new line.

GitHub processes live requests under its account policies and data-handling terms. Disconnecting or forgetting the saved PAT does not delete data already sent to GitHub.

This project is not affiliated with GitHub. The extension stores nothing in Chrome, sends no analytics, and never retries a failed request on its own.
